## 這份實驗要回答的問題

禁令「不要用 `deepseek-flash` 跑 code review」的證據來自 **shell 標的**（2026-09-20，
4 個技術斷言錯 3 個）。三方實驗在 **Python 標的**得到相反結果（6/7、0 誤報），
但兩個變因同時不同，推翻不了禁令。這次把標的型態補齊，每組各跑 3 次。

## 主結果

| 組別 | 成功率 | 平均召回 | 誤報總計 |
|---|---|---|---|
| python / **v4-pro** | **3/3** | 4.7 / 7 | **0** |
| python / flash | 2/3 | 4.0 / 7 | **4**（B1、B2 每次都中） |
| shell / **v4-pro** | **3/3** | 4.7 / 7 | 3 |
| shell / flash | 1/3 | 6.0 / 7 | 1 |

加上追加的 3 次與 smoke：**flash 共 10 次跑、3 次輸出無法解析（30%）；v4-pro 6/6 全成功。**

## 結論一：禁令保留，但理由要換

原本的理由是「技術斷言錯」。這次量到的問題**更基本**：

1. **輸出可用率**。flash 30% 的機率吐出無法解析的 JSON，v4-pro 零。
2. **誤報**。Python 標的上 flash **每次都同時中兩個誤報探針**（B1、B2 各 2/2），
   v4-pro 是 **0/3**。B1/B2 的設計是「與該報項同形狀、只差一個條件」，
   全中代表在做模式比對而非語義判斷。
3. **斷言仍然會錯**。S3 這一格 flash 說「會拋出 integer expression expected
   **並使該次同步中斷**」——前半對、**後半錯**（腳本沒有 `set -e`，不會中斷）。
   v4-pro 兩次都只說「比較出錯，或 SQL 插入失敗」，沒有多做宣稱，而且
   **都抓到了下游 SQL 會拿到空值**這個連鎖。

⇒ 跨標的型態都成立，不再只是 shell 標的的結論。

## 結論二：那 3 次失敗不是 max_tokens 截斷

證據鏈：

| 觀察 | 說明 |
|---|---|
| 截斷偵測有效 | 對照組 `--max-tokens 500` 正確報「輸出被 max_tokens=500 截斷（content 996 字元）」 |
| 額度遠遠夠用 | 成功那次 `completion_tokens` 只有 **2031**，額度給到 **16384** |
| 失敗時沒有截斷提示 | ⇒ API 回的 `finish_reason` **不是** `length` |
| 但 content 確實不完整 | 其中一次結尾是**半個中文字**（`明確的注` + 破碎位元組） |

⇒ **API 回了不完整的內容，卻沒有標示為截斷。** 三次失敗的 JSON 畸形形態各異
（`column 2` / `找不到 JSON 物件` / `column 185`），不是單一 bug。
根因在 API 側，**未進一步確認**。

⚠️ 附帶發現：`extract_json` 的第二層 fallback 用 `text.rfind("}")`，
content 被切斷時會抓到中間某個 `}`，切出語法錯誤的片段——所以**錯誤訊息會指向
奇怪的位置**（column 2），看起來像格式問題而不是內容不完整。
`deepseek_review.py:464` 只印 `content[:2000]`，不足以診斷。

## 結論三：兩個一致盲點（四組全部 0）

| 埋點 | 四組表現 |
|---|---|
| **S6 固定 `/tmp` 路徑**（symlink 攻擊、多實例覆寫） | 0/3、0/1 — 完全沒報 |
| **C1 缺測試** | 0/3 全部沒報 → **確認 rubric 第 6 條等於沒作用** |

C1 這格很重要：預期表寫「報了反而是新發現」，結果**四組零命中**，
印證了先前「10 次跑 8 次 0 筆」的記載。⚠️ 第一版分析腳本曾誤判它命中 2/3，
原因是只比行號——line 59 的「`classify` 假設一定有 `additions` 鍵」（成立的 bonus）
被算成 line 58 的 C1。**行號相鄰不代表講同一件事**，見 `locate-by-snippet-not-line-number`。

Python 標的上 **A4「迴圈內 HTTP I/O」也是四組零命中**（三方實驗時 flash 漏的就是這個）。

- **標的型態與有無專屬規則檔無法分離**：`prompts/rules/` 只有 `python.md`，
  shell 標的沒有專屬規則。shell 表現若較差，不能斷定是模型讀不懂 shell。
