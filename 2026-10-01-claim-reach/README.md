### ① 的定義

- **窄版**（建議的改法已經在 head 裡，字面存在）：機制跟 ③ 一樣是「找到就丟」，併進 ③，射程也在上面那 7–10 則裡
- **寬版**（事情已經被處理，包括註解寫明的刻意決策、README 的 TODO）：要判斷語意，做不成確定性規則；用 LLM 判斷就是 v1.2.0 失敗的那一型（自我約束，誤刪 15 : 刪對 4）
- 我們自己的樣本（`annotated-code-review-blindspot`，25 筆裡 6 筆「已經處理了」）也是寬版居多：字面上 code 已經存在的乾淨例子只有 1 筆（`last_err = None`）

## 已知限制

- regex 抓的是「句型在射程內」，不是「真的反駁得掉」。射程是上限：射程內的錯誤 comment，grep 也不一定找得到反證
- ① 窄版（建議的改法已經在 head 裡）要看 code 才判得出來，note 文字估不了，這裡只做定義分析
- AACR 的 comment 來自多個模型；我們 kit（v4-pro）的誤報組成可能不同
