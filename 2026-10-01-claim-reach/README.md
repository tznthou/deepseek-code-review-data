## 已知限制

- regex 抓的是「句型在射程內」，不是「真的反駁得掉」。射程是上限：射程內的錯誤 comment，grep 也不一定找得到反證
- ① 窄版（建議的改法已經在 head 裡）要看 code 才判得出來，note 文字估不了，這裡只做定義分析
- AACR 的 comment 來自多個模型；我們 kit（v4-pro）的誤報組成可能不同
