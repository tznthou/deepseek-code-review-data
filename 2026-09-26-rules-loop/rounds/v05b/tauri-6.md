## 🤖 DeepSeek Code Review — 🛑 建議修改後再合併

<details><summary>🛑 <b>Blocker</b> — <code>crates/tauri/mobile/android/src/main/java/app/tauri/AppPlugin.kt:46</code> AppPlugin 強制轉型 activity 為 AppCompatActivity，可能導致 ClassCastException</summary>

在 init 區塊中，`(activity as AppCompatActivity)` 直接將傳入的 Activity 轉型為 AppCompatActivity。如果 TauriActivity 不是繼承自 AppCompatActivity（例如使用 ComponentActivity 或其他 Activity 子類別），此轉型會拋出 ClassCastException，導致應用程式崩潰。

建議：檢查 activity 是否為 AppCompatActivity，若不是則使用其他方式取得 OnBackPressedDispatcher，或改用 ComponentActivity 的 onBackPressedDispatcher（需確保最低 API 等級）。

**判斷依據**：diff 中新增的 AppPlugin.kt 第 39 行：`(activity as AppCompatActivity).onBackPressedDispatcher.addCallback(activity, callback)`

</details>

<details><summary>⚠️ <b>Major</b> — <code>crates/tauri/permissions/app/autogenerated/reference.md:12</code> 將 register_listener 與 remove_listener 加入預設權限可能擴大攻擊面</summary>

此 PR 將 `allow-register-listener` 與 `allow-remove-listener` 加入 app plugin 的預設權限。這表示任何前端程式碼都可以註冊或移除任意事件的監聽器，包括可能敏感的內部事件。若應用程式依賴權限系統來限制前端對某些功能的存取，此變更可能繞過這些限制。

建議：評估是否真的需要將這兩個權限設為預設，或改為讓開發者自行在 capabilities 中啟用。

**判斷依據**：diff 中 reference.md 新增的兩行權限，且位於 Default permissions 區塊。

</details>

<details><summary>⚠️ <b>Major</b> — <code>crates/tauri/mobile/android/src/main/java/app/tauri/AppPlugin.kt:34</code> 返回鍵處理邏輯可能導致非預期的行為</summary>

當沒有監聽器且 WebView 無法回上一頁時，程式碼會停用 callback、呼叫 `activity.onBackPressed()`，然後重新啟用 callback。然而，`activity.onBackPressed()` 在 AppCompatActivity 中會觸發預設的返回行為（通常是 finish activity）。若 activity 不是 AppCompatActivity，此呼叫可能不存在或行為不同。此外，在呼叫 `onBackPressed()` 後立即重新啟用 callback，可能導致下一次返回鍵事件再次進入此邏輯，造成遞迴或非預期行為。

建議：明確處理返回鍵的預設行為，例如直接呼叫 `activity.finish()` 或使用 `OnBackPressedDispatcher` 的預設 callback，避免依賴 `onBackPressed()`。

**判斷依據**：diff 中 AppPlugin.kt 第 27-29 行。

</details>

<details><summary>🔸 <b>Minor</b> — <code>crates/tauri/src/app/plugin.rs:138</code> Android plugin 註冊使用 `?` 可能導致 setup 失敗</summary>

在 `.setup()` 閉包中，`_api.register_android_plugin(...)?` 使用 `?` 運算子。如果註冊失敗，整個 plugin 初始化會失敗，可能導致應用程式無法啟動。雖然註冊失敗通常代表嚴重錯誤，但建議考慮記錄錯誤並回傳 Ok，或提供更明確的錯誤訊息。

**判斷依據**：diff 中 plugin.rs 新增的 setup 閉包。

</details>
