# 迭代 loop 主控檔：rules

## Metric
- 形態：L2 量化（程式算，$0）
- 主 metric：調參組的**引用命中** recall（`loop_score.py` 的 `M_cited_hit`；分母 188 則規則類標準答案）
- 判定用**同一設定兩次 run 的平均**（標籤 vNNa、vNNb）
- keep：平均 M ≥ 目前最佳 + δ，且 `guard.py vNNa vNNb` exit 0
- δ：v01 兩次 run 之後定 = max(2pp, 2 × |v01a − v01b|)，**定了就不改**
- 提早收工：平均 M ≥ 0.44
- Anti-criteria（由 `render.py` 在結構上保證，違反 = 設定檔過不了 `render.check`）：
  - 規則文字只能逐字取自 `rules_for_repo.jsonl`，標準答案的任何內容不得進 prompt
  - 不得出現要求自我約束的指示（「確定才報」「避免誤報」）；開頭說明只能選 h1／h2／h3
  - rubric（system prompt）不得變動（G3）

## Guard
- 指令：`python3 scripts/guard.py vNNa vNNb`
- 完整性：調參組 69 個 PR 每次都要有輸出
- G1：功能性位置命中（兩次平均）≥ v00 − 2pp（v00 調參組平均 0.568 → 門檻約 0.548）
- G2：高信心未對上／PR（兩次平均）≤ v00 × 1.15（v00 平均 0.65 → 門檻約 0.75）
- G3：`guard-targets.sha256` 全部 OK（Target files 見該檔；loop 期間不得修改）
