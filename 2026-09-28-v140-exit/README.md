## 結果（2026-09-27 19:1x UTC，`blind/results.json`）

**判決：保留 v1.4.0。** ① 不成立（+8 則 < 10）；② 不成立（v1.3.1 最低 149 ≤ v1.4.0 最高 151）。

| 功能性缺陷 309 則 | v1.4.0（base-1／base-2） | v1.3.1（v131-1／v131-2） |
|---|---|---|
| **S：行內那層（信心 ≥ 0.7）同一問題**，第一輪、同一批新標籤 | **122**（39.5%） | **130**（42.1%） |
| **L：行內那層位置命中** | **151／149** | **160／149** |
| 信心 ≥ 0.6 那層的同一問題 | 137 | 137 |
| 〔未預先登記〕全部信心層級的同一問題 | 142（≥ 0.6 新標籤＋< 0.6 用 09-25 舊標籤） | 137 |
| 仿 post_review 門檻（≥ 0.7、嚴重度 ≥ minor、定位得到）的同一問題 | 117 | 124 |
| finding 數 | 347／362 | 331／325 |
| 信心 ≥ 0.7 的 finding（≈ 會貼行內的量） | 270／278 | 294／288 |
| 高信心未對上／PR（位置判定，未對上 ≠ 誤報） | 0.91／0.90 | 0.93／1.00 |

讀法：

- **方向是舊版在行內那層略高，但沒過事先寫死的門檻**：S 多 8 則（2.6pp，門檻 10 則）。同一份 rubric 跑兩輪，位置命中就差 11 則（v131-1 160、v131-2 149），+8 落在單輪雜訊的量級裡——② 要擋的正是這種單輪運氣，這次它擋下了
- **機制對得上「信心改排序訊號」**：信心 ≥ 0.6 那層兩版都是 137 則，差別只在 0.6–0.7 這一帶——v1.4.0 把一部分真問題打到 0.7 以下，改列在摘要表、不貼行內。低於 0.6 另外多撈到 5 則（只在摘要表）
- **v1.4.0 的行內留言比較少**：信心 ≥ 0.7 的 finding 少約 6%（兩輪平均 274 vs 291，差 17 則）；高信心未對上兩臂平均 0.905 vs 0.965／PR，差 0.06——同一份 v1.3.1 rubric 兩輪之間就差 0.07（0.93 vs 1.00），分不出來
- **標記品質**：主 session 抽樣 vs 標記員，三類 30/30、same 與否 30/30；漂移（base-1 新 vs 09-25 舊）same 與否 407/413（98.5%）、三類 387/413（93.7%）

沒量到、要寫進結案 CHANGELOG 的：真實 PR 上的誤報、信任邊界型誤報（v1.4.0 8/10、舊版 1/9 那個事後假說）、摘要表變長有沒有人看。
